## 📌 About The Project

**Pandas Analyzer & Data Visualization** is a Python-based project designed to analyze sales datasets and perform essential data manipulation, statistical analysis, and visualization operations.

The project uses an object-oriented approach to organize data analysis functionality into a structured, menu-driven application.

Users can load CSV datasets, explore records, handle missing values, perform mathematical calculations, analyze statistics, and generate visualizations through an interactive terminal interface.

### 🎯 Project Objectives

- Understand real-world data analysis using Pandas.
- Perform numerical operations using NumPy.
- Apply data cleaning and preprocessing techniques.
- Analyze sales and profit data using statistical methods.
- Create meaningful charts using Matplotlib and Seaborn.
- Practice object-oriented programming in Python.

---

## ✨ Features

### 📂 1. Dataset Management
- Load sales data from CSV files.
- Explore the first and last five records.
- Display column names and data types.
- Inspect dataset information.

### 🧹 2. Data Cleaning
- Identify rows containing missing values.
- Fill missing numeric values using the mean.
- Remove rows containing missing values.
- Replace missing values with a specified value.

### 🔢 3. NumPy Operations
- Convert sales data into NumPy arrays.
- Perform array indexing.
- Extract array slices.
- Explore numerical data manipulation.

### 🧮 4. Mathematical Operations
- Add values to sales figures.
- Multiply sales values.
- Calculate sales minus profit.
- Calculate profit margins.

### 🔍 5. DataFrame Operations
- Search records by product.
- Sort sales in ascending or descending order.
- Filter records using sales values.
- Combine datasets using concatenation.
- Split records by region or product.

### 📈 6. Statistical Analysis
- Generate descriptive statistics.
- Calculate sales totals and averages.
- Calculate standard deviation and variance.
- Calculate quantiles and percentiles.
- Count available sales records.

### 📊 7. Advanced Pandas Operations
- Generate pivot tables.
- Group sales by product.
- Calculate region-wise sales totals.
- Transform data using GroupBy operations.
- Set a column as the DataFrame index.
- Convert supported column data types.

### 🎨 8. Data Visualization

Create different visualizations to explore sales data:

| Visualization | Purpose |
|---|---|
| Bar Plot | Compare sales across products |
| Line Plot | Visualize sales trends |
| Scatter Plot | Explore relationships between variables |
| Pie Chart | Show regional sales distribution |
| Histogram | Examine sales distribution |
| Stack Plot | Visualize sales and profit values |
| Heatmap | Explore numerical correlations |
| Box Plot | Compare sales distributions across regions |
| Subplots | Display multiple charts in one figure |

### 💾 9. Export Visualizations
- Save generated plots to files.
- Use supported image and vector formats such as PNG, JPEG, PDF, and SVG.

## ⚙️ Installation & Setup

### Prerequisites

Make sure the following are installed on your system:

- Python 3
- Git
- A GitHub account

### Step 1: Clone the Repository

```bash
git clone https://github.com/SHAIKH-000/Pandas-Analyzer-Data-Visualization.git
```

### Step 2: Navigate to the Project Directory

```bash
cd Pandas-Analyzer-Data-Visualization
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
python main.py
```

## 🚀 How To Use

1. Start the Python application.
2. Select the dataset loading option.
3. Enter the path to your CSV file.
4. Explore the dataset and inspect its columns.
5. Perform cleaning, filtering, sorting, or statistical operations.
6. Generate visualizations using the interactive menu.
7. Save charts when required.
8. Select the Exit option to close the application.

**Note:** The dataset must contain the columns required by the selected operation. Depending on the operation, these may include `Sales`, `Profit`, `Product`, `Region`, `SalesID`, `Year`, or `Date`.
